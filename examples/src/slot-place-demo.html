Slots & Place

Named content projection and placing nodes into another container.

Slots

Two sides:

  • Layout draws holes: <${Slot} name="trigger">
  • Parent fills them: <button slot="trigger">

A child without slot (and non-empty text) goes into the unnamed <${Slot}>. Click Ping or edit the title — handlers, {this.state.title}, and ref="ping" belong to the parent (this.refs.ping), not to the layout.

class SlotLayout extends Component(HTMLElement) {
  render() {
    return html`
      <${Slot} name="trigger"></${Slot}>
      <${Slot} name="content"></${Slot}>
      <${Slot}></${Slot}>
    `;
  }
}

<${SlotLayout}>
  <button slot="trigger" onclick="{this.ping}">Ping</button>
  <p slot="content">{this.state.title}</p>
  <span>default</span>
</${SlotLayout}>

Place

<${Place} to="body">
  <div class="menu">{this.state.title}</div>
</${Place}>

to is body or a querySelector selector (to="{this.state.target}" is interpolated). Nodes are removed when the place disconnects. Close on the overlay finds the parent method (this.close).
