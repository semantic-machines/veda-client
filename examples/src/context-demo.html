Context

Share values with descendants without passing :prop through every layer.

Usage

import Component, { html, Context } from 'veda-client';

class AppShell extends Component(HTMLElement) {
  constructor() {
    super();
    this.state.theme = 'light';
    this.state.locale = 'ru';
  }
  toggleTheme() {
    this.state.theme = this.state.theme === 'light' ? 'dark' : 'light';
  }
  render() {
    return html`
      <${Context} :theme="{this.state.theme}" :locale="{this.state.locale}">
        <status-bar></status-bar>
        <button onclick="{this.toggleTheme}">Toggle</button>
      </${Context}>
    `;
  }
}

class StatusBar extends Component(HTMLElement) {
  render() {
    return html`<span>{this.context.theme} · {this.context.locale}</span>`;
  }
}
  • Provide with <Context :key="{...}">
  • Read with this.context.key
  • Nearest provider that has the key wins; other keys fall through
  • Methods use onclick="{this.toggleTheme}", not Context
