bind & refs

Two-way bind on native controls, and named DOM refs after render.

Usage

<input ref="query" bind="{this.state.q}">
<input type="checkbox" bind="{this.state.done}">
<select bind="{this.state.kind}">...</select>
<input type="radio" name="via" value="open" bind="{this.state.via}">
<input type="radio" name="via" value="closed" bind="{this.state.via}">

this.refs.query.focus();
  • bind is a directive, not :prop and not a native property
  • Simple path only: {this.state.q} (?. is allowed)
  • Text / textarea use input; checkbox / radio / select use change
  • Checkbox stores a boolean; radio stores the selected value string
  • this.refs is rebuilt on each update()
  • Same as :value + oninput if you prefer a method
